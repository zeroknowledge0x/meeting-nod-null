A single-line software patch note for a bug in real life: nodding through a meeting flips the confidence flag while understanding never loads. Under 160 characters, written in the terse register of a real release note.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node --experimental-strip-types main.ts
cat /tmp/out/entry.txt
```

The program is deterministic: no clock, no random source, no network call and no secret reach the output. It writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`) with no trailing newline, and refuses an entry outside 1-160 characters.
